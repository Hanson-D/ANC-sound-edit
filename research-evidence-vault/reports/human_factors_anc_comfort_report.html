Test Rationale

1 kHz 压不下去时，更要调它前后两个频段

这次测试不是为了证明“降噪越深越好”，而是要验证一个关键人因假设：当 1 kHz 附近因能力限制无法继续压低时，500-1000 Hz 与 2-4 kHz 的降噪深度会决定 1 kHz 残留是被掩蔽、被接受，还是被凸显成耳压和闷头感。

测试目标

不是加深 1 kHz，而是管理相对残留

  • 固定约束1 kHz 能力压不下去
  • 可调变量1 kHz 前后频段深度
  • 核心风险相邻频段太深导致 1 kHz 凸显
  • 研究目标找到舒适的相对谱形
设备侧动作

要测试的就是前后两个位置

  • 前段500-1000 Hz 回退 / 保持 / 加深
  • 中心1 kHz 附近保持能力上限
  • 后段2-4 kHz 回退 / 保持 / 加深
  • 观察残余峰、耳压、自然感变化
关键假设

为什么现在体验差

如果 500-1000 Hz 和 2-4 kHz 都比竞品更深，而 1 kHz 附近压不下去，用户实际听到的会是一条“中间凸、两边凹”的残余谱。它可能比整体浅一点但连续的曲线更闷、更顶、更像有耳压。

人因侧要验证的主客观关系

相邻频段越深，1 kHz 是否越突兀
低中频回退是否降低闷头
高中频回退是否恢复自然感
谱形平滑度是否预测舒适偏好
降噪感与耳压之间的 trade-off

对合作方的核心请求：请提供几条只改 1 kHz 前后频段的可测曲线。人因测试会回答“哪种相邻频段组合让用户觉得最舒适”。

Parameter Test Design

把调参目标从“压 1 kHz”改成“降低 1 kHz 的相对凸显”

既然 1 kHz 附近受硬件、声学路径或稳定性限制压不下去，继续要求中心频点加深并不能解决体验问题。更可行的策略是控制 1 kHz 前后频段，减少残余谱峰谷差，让用户感知到更连续、更少压迫的声场。

1 kHz 能力固定
≈
调前段
+
调后段，降低相对峰
这不是“把降噪做浅”的保守方案，而是在中心频点受限时，用相邻频段塑造更舒适的残余谱。人因测试要证明：局部少 2-3 dB 降噪，可能换来更低耳压和更高总体偏好。

建议请设备侧输出的曲线

  • A当前量产/当前调试曲线
  • B只回退 500-1000 Hz
  • C只回退 2-4 kHz
  • D前后两段同时回退
  • E前后两段做轻微平滑过渡

人因测试读数

  • 主指标总体舒适偏好
  • 风险项耳压、闷头、头内感
  • 解释项1 kHz 残留突兀感
  • 保底项降噪感不能明显掉线
